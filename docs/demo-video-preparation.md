# 演示视频准备

子女导出页的 9 个截图案例、3 个写话示例均已准备普通话和河南话视频，共 24 条，位于 `public/demo/exports/`。原首页“先看一个成片”的两条 P3 视频仍保留在 `public/demo/`。

未修改的示例显示“演示视频已提前制作”，点击“打开演示视频”直接读取 MP4，不调用现场合成接口。文字、标题、配图或语言与预制清单不匹配时，页面提示需要现场制作。缺失预制文件会报错，不会悄悄调用在线合成。

长图直接保存，无需勾选核对项。“还没说清的地方”和沟通建议仍只在子女页面显示，不进入长图或视频。

重新准备、验收与构建：

```sh
npm run prepare:videos
npm run verify:videos
npm run build
```

准备脚本复用导出页的分页和绘制逻辑，缓存每页配音，可断点继续。准备新内容需要配置好的语音服务和 FFmpeg；已备好的视频播放不需要这些服务。`verify:videos` 完全离线，检查全部 24 条的正文、配图、文件哈希、720×1280 H.264 画面和非静音 AAC 音轨。

GitHub Pages 静态版只播放与当前内容匹配的预制视频，不能现场合成修改后的新视频；本地 `4174` 版本仍可现场生成。静态发布准备见 [github-pages.md](github-pages.md)。

脚本默认使用 macOS 的中文字体；其他环境可用 `JIALIHUA_DEMO_FONT` 指向本机中文字体。布局或旁白规则变更时，更新 `src/demo-video-sources.mjs` 中的版本并重新准备视频。修改演示文案或配图后也应运行上述命令，确保预制清单与当前内容一致。
